# The Adventure of Us — Sunset Bay

An original, lightweight third-person 3D birthday adventure inspired by open-world games. Explore a small seaside town, talk to five characters, collect four memories, complete a quiz and discover the birthday garden.

## How to play
- Desktop: WASD or arrow keys, shift to run, drag the screen to turn the camera, E to talk.
- Mobile: on-screen joystick, drag to turn the camera, TALK button.

## Personalize
Edit the `CONFIG` object in index.html with your names, shared memories, relationship quiz and birthday letter. This repository is public, so avoid adding sensitive details or private photos.

## Hosting
Enable GitHub Pages in Settings → Pages → Deploy from a branch → main / root. The game needs an internet connection to load its pinned Three.js module and a WebGL-capable browser. No server or build step is required.
